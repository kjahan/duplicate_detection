# duplicate_detection
Detect duplicate objects with images, texts, and categorical features

## Problem
It seems companies like Walmart or Amazon have these problem where they have many many identical products uploaded by the same seller or different sellers. For example, different colors of a T-shirt with the same brand but differerent color. How would you identofy such duplicate product and put them in the same cluster?

## Use Cases
This has many use cases. For example, organize products and present the same product but different color to the buyer so that they have enough choice to pick what they prefer.

## Technical Challenges
One aspect of the problem is that the products have a mixture of objects like product images, description, and categorical features like price, date of upload, the seller name etc. How could you leverage all of these mixed data and use them when detecting identical items. Sometimes two images are very identical to human eye but there is a small difference and that make the algo to fail detecting them. We need real data from Walmart, Amazon or FB marketplace to develope and test this.
